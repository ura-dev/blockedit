# 計測対象のパスをソースに書かない

`bench/` が何を測るかは `bench/targets.json`(git管理外)が持つ。読むのは
`bench/_targets.py` 1箇所だけで、各ベンチはそこから import する。雛形は
`bench/targets.example.json`。

**手元のリポジトリのパスや、そこにあるドキュメントの中身を、追跡されるファイルに
書かない。**example 側に置くのは実在しない汎用の見本に限る。

# 本体を複製しない

分割・ゲート・サンプラーはリポジトリルートのランナーをそのまま import する。
**1バイトでも違うと計測が本番を代表しなくなる。**ベンチ用に書き写した版を作らない。

測った結果は勝率と件数で残す。ベンチが出力する生ログ(`bench/out/`)はgit管理外で、
残す価値があるものは `feedback/` に人力で拾う。
